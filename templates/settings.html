Telegram Setup Guide
  1. Message @BotFather on Telegram → /newbot → copy the token
  2. Each employee messages the bot → it replies with their Chat ID
  3. Add the bot to your group chat for check-in notifications
  4. Add the bot to Sales Team, then send /salesgroup in that group to connect lead notifications and commands
  5. Add the bot to HR Team, then send /hrgroup in that group to connect monthly attendance and daily staff reports
  6. To remove a mistaken HR report post, reply to that bot message with /deletereport
  7. Paste the Bot Token and Group Chat ID above, then click Save Settings
  8. Alternatively, set via server environment variables as a fallback
