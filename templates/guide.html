Standards Guide

Follow these conventions when adding tasks, projects, clients, and other data. Consistency helps everyone.

Task Names

Start with a verb, be specific enough that someone else can do it.

GoodAvoid
Create Blog for Cross Posting - Offpage - LECBlog — too vague
Update SEO Meta Tags - Onpage - AcmeSEO update stuff — no filler words
Send Monthly Analytics Report - Reporting - TechFlowReport — says nothing
Design Social Media Creatives - SMM - GlobalTradeSocial media design work to be done — wordy
Upload social media postsSM — abbreviations confuse
Rules:
  1. Start with a verb: Review, Update, Send, Prepare, Check, Submit, Upload, Follow up, Reconcile, Process
  2. Be specific — if you read it 6 months later, would you know what to do?
  3. No ALL CAPS or special characters
  4. Include the what, not the how: "Prepare monthly MIS report" not "Open Excel and fill data and email"
  5. Don't include frequency in the name — the system tracks that automatically

Task Descriptions

Optional but valuable. Write it so a new team member can do the task without asking questions.

Project Names

One project = one client retainer. Tasks inside handle the service-level detail.

GoodAvoid
Acme — Digital Marketingacme website project thing
TechFlow — Monthly BookkeepingBookkeeping — which client?
Dr. Sharma — GST ComplianceGT GST — unreadable
Internal — Office OperationsOffice stuff
Rules:
  1. Format: Client Name — Retainer Scope
  2. Use title case: "Acme — Digital Marketing" not "acme - digital marketing"
  3. For internal work, prefix with "Internal —"
  4. Keep under 50 characters — it shows in dropdowns
  5. Only create multiple projects for the same client if they have separate retainer contracts
Structure: Project = client engagement. Tasks = the actual work inside it.
Acme — Digital Marketing
  Recurring: Create Blog for Cross Posting - Offpage (weekly)
  Recurring: Design Social Media Creatives - SMM (daily)
  Recurring: Send Monthly Analytics Report - Reporting (monthly)
  One-Time: Setup Landing Page - Website

Client Names

Use the full registered or trading name. Contact person goes in its own field.

GoodAvoid
Acme Industries Pvt LtdAcme — there could be multiple
TechFlow Solutionstechflow — no lowercase
Dr. Sharma Clinicsharma — not a company name
Rules:
  1. Full business name in title case
  2. Include Pvt Ltd / LLP / LLC if applicable — helps with invoicing
  3. No abbreviations unless the company itself uses one (IBM, HCL)
  4. Notes field: add retainer terms, billing cycle, key contacts
