Standards Guide

Task Names

Start with a verb, be specific enough that someone else can do it.

GoodAvoid
Create Blog for Cross Posting - Offpage - LECBlog — too vague
Update SEO Meta Tags - Onpage - AcmeSEO update stuff
Send Monthly Analytics Report - Reporting - TechFlowReport — says nothing
Design Social Media Creatives - SMM - GlobalTradeSocial media design work to be done
Rules: Start with a verb (Review, Update, Send, Prepare, Check, Submit) • Be specific • No ALL CAPS • Include the what not the how • Don't put frequency in the name

Task Descriptions

TypeWhat to WriteExample
RecurringSteps or SOP linkDraft > Review > Publish on WordPress
One-TimeContext + deadlineMust go live by Friday

Project Names

One project = one client retainer. Tasks inside handle the service-level detail.

GoodAvoid
Acme — Digital Marketingacme website project thing
TechFlow — Monthly BookkeepingBookkeeping — which client?
Internal — Office OperationsOffice stuff
Format: Client Name — Retainer Scope • Title case • Under 50 chars • Internal work: prefix with "Internal —"
Structure: Project = client engagement. Tasks = actual work.
Acme — Digital Marketing
  • Recurring: Create Blog for Cross Posting - Offpage (weekly)
  • Recurring: Design Social Media Creatives - SMM (daily)
  • One-Time: Setup Landing Page - Website

Client Names

GoodAvoid

Full business name • Title case • Include Pvt Ltd / LLP if applicable • No abbreviations unless official (IBM, HCL)
